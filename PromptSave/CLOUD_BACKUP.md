# PromptSave 七牛云手动备份

PromptSave v0.5.0 支持使用七牛 Kodo 的 S3 兼容接口手动上传和下载备份 ZIP，每次由用户主动备份或恢复，不提供实时双向同步。

## 配置与使用

1. 打开「设置 → 存储 → 七牛云备份（自行配置）」。
2. 填写自己在七牛控制台使用的 S3 存储桶 HTTPS 地址，格式为 `https://你的存储桶.s3.你的区域.qiniucs.com`。只支持该格式的七牛 S3 虚拟主机地址，不要填写 CDN 下载域名、对象路径或查询参数。若 S3 存储空间名称与原 Kodo 空间名不同，请使用控制台显示的 S3 名称。地址输入框默认隐藏内容。
3. 填写自己的 `AccessKey` 和 `SecretKey`，然后在「设置 → 导入导出」中使用「上传云端」「云端导入并合并」或「云端导入并替换」。本地 ZIP 操作仍可使用；操作区在窄窗口中可横向滚动。

上传会把当前本地数据打包成 ZIP，并通过 S3 `PUT` 写入固定对象 `promptsave/backup.zip`；再次上传会覆盖同一个对象。下载通过 S3 `GET` 读取该对象。云端导入下载后进入与本地 ZIP 相同的解析、数据和图片校验及导入流程；合并沿用现有合并逻辑，替换沿用现有替换逻辑并保留恢复副本。

请求签名在扩展本机使用 Web Crypto 计算 AWS Signature V4。发布包不包含预设的存储桶地址、AccessKey 或 SecretKey。endpoint 和 AccessKey 保存在本机 `chrome.storage.local`；SecretKey 只保存在 `chrome.storage.session`，浏览器重启后会清除，需要重新输入。SecretKey 不作为明文请求字段发送，但扩展环境不应被不可信人员使用。

## 限制与安全

- 云端上传、下载及本地 ZIP 导入导出均受 32 MiB 大小上限限制。
- ZIP 可能包含提示词、图片和回收站内容。请将七牛存储空间设为**私有**，避免备份对象被公开读取。
- 固定对象会被后一次上传覆盖；需要保留历史版本时，请在七牛侧按实际服务和费用情况配置版本管理，或另存本地 ZIP。
- 浏览器系统时间需要准确，否则 S3 请求签名可能被拒绝。

## 常见错误

- `HTTP 403 / SignatureDoesNotMatch`：检查 endpoint 中的存储空间名称、S3 区域、AK/SK 和本地时间。
- `HTTP 404 / NoSuchKey`：该存储桶尚未上传 `promptsave/backup.zip`，或当前配置指向了其他存储桶。
- 无法连接：检查 HTTPS S3 地址、网络和扩展访问相关网站所需的权限。
