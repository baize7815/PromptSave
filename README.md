## 这是什么

PromptSave 是一个 Chrome / Edge 浏览器扩展（Manifest V3），为 AI 绘画、写作与编程工作流收藏**提示词文本**和**参考图片**：

- 在网页上选中文字或图片，**右键一次**即完成收藏，标题自动生成；
- 在浏览器侧边栏里分类、搜索、批量整理、回收站恢复；
- 数据始终保存在**本机**——浏览器内部存储、你指定的文件夹，或经可选的 Windows 本地桥接直接落盘；
- 可随时导出 ZIP 迁移，收藏数据不上传到 PromptSave 的服务器，无需账号或云服务。

## 为什么需要它

提示词和参考图散落在聊天记录、网页和图床里，回头找不到、复制丢换行、图片会失效；云端收藏工具需要账号联网，内容经过别人的服务器；浏览器书签不存正文和图片，笔记软件又要手动来回粘贴。PromptSave 用一次右键解决收藏，用文件夹级的数据主权解决信任。

## 功能特性

### 一键收藏

- **右键「收藏选中文字」**：完整保留换行、中英文、表情与特殊符号，标题自动取首个非空行的前 24 个字符，无需手动命名。
- **右键「收藏图片」**：网页图片存为独立图片条目，支持登录站点与 `blob:` 临时图片；读取失败会明确报错，绝不误报收藏成功。
- **剪贴板监听**：工具栏一键开启后，在禁止右键保存的站点（如小红书）右键「复制图片」即可自动收藏；同一张图按哈希去重。监听状态只存在于当前浏览器会话，**重启浏览器必定关闭**，不会静默监听。
- **手动添加**：右上角 ＋ 新建条目，支持选择本地图片，也可以直接粘贴剪贴板里的图片。

### 整理与查看

- 侧边栏管理，↗ 一键打开为独立标签页；网格 / 列表两种视图。
- 分类新建、重命名、删除；删除分类不会删除条目，它们自动归入「未分类」。
- 标题与正文搜索、四种排序、分页浏览。
- 批量模式：按当前筛选结果全选或多选，批量修改分类、批量删除。
- 回收站软删除，可恢复到原分类；永久删除与清空回收站均有二次确认。
- 一键复制完整提示词，长文本保留原始换行；支持中文 / English 双语与明亮 / 暗黑主题。

### 图片自动压缩

图片只在**收藏保存时压缩一次**，之后查看、导入、导出都不会重复压缩或改写原文件：

| 图向 | 输出尺寸上限 |
|---|---|
| 横图 | 1280 × 720 |
| 竖图 | 720 × 1280 |
| 方图 | 720 × 720 |

- 统一输出 JPEG（质量约 0.76），目标体积约 192 KiB，单张硬上限 512 KiB；小图不放大，透明区域补白底。
- 输入图片超过 12 MiB 或 2000 万像素时，在解码前直接拒绝，避免页面崩溃。

### 数据放在哪里：三种存储模式

| 模式 | 数据位置 | 特点 |
|---|---|---|
| **扩展内部存储**（默认） | 浏览器扩展存储（`chrome.storage.local`） | 零配置、开箱即用；不受网页存储清理影响 |
| **浏览器文件夹** | 你选择的本机文件夹，经 File System Access API 读写 | 数据就是明面上的 `data.json` 与 `images/*.jpg`，可用资源管理器查看；浏览器重开后可能要求重新授权 |
| **Windows 本地桥接**（可选） | 同一个文件夹，经 Python 原生消息宿主读写 | 授权一次、重开浏览器不再弹授权；工具栏按钮可直接打开数据文件夹；仅支持 Windows |

三种模式之间可在设置中随时迁移。选择已有数据的文件夹时，扩展会询问「使用该数据集」还是「合并当前收藏」，**不会静默覆盖**；检测到外部程序改动过数据（修订号变化）会报冲突而不是强行覆盖。目录暂时不可写时，新收藏进入待保存队列，恢复后重试，只写入一次。

### 备份与迁移

- **导出 ZIP**：包含 `data.json`、全部图片与回收站记录；**导入**支持「合并」（自动去重，回收站中的旧条目不会被悄悄恢复）与「替换」（替换前自动保留恢复副本）两种方式。
- 安全上限：导入 ZIP ≤ 32 MiB、解压后 ≤ 64 MiB、单张图片 ≤ 12 MiB；在改动任何现有数据前，拒绝损坏 ZIP、路径穿越（`../`）、伪装成图片的文件与无 `data.json` 的压缩包。
- 单库上限 5000 条 / 8 MiB 元数据，达到上限时拒绝继续写入并保留原库。

## 安装

1. 从 [v0.3.0 发行版](https://github.com/baize7815/PromptSave/releases/tag/v0.3.0) 下载 `PromptSave-v0.3.0.zip` 并解压，或克隆本仓库。发行包的根目录就是扩展本体；仓库中的扩展本体位于 **`PromptSave/` 子目录**。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹（发行包解压目录，或仓库中的 **`PromptSave/`**）。
4. 建议将 PromptSave 固定到工具栏；点击图标即可打开侧边栏。

无需构建步骤、无需 npm 安装：扩展是纯原生 ES Module，唯一的第三方库 JSZip 已随仓库本地打包。

### Windows 本地桥接（可选）

需要「重开浏览器免重新授权」和「一键打开数据文件夹」时：

1. 在扩展管理页重新加载扩展，复制 PromptSave 的扩展 ID；
2. 双击 `PromptSave/native/install.bat`，按提示粘贴扩展 ID（Chrome 与 Edge 同时使用可用逗号分隔填入两个 ID）；
3. 在扩展设置中点击「连接本地目录（免重复授权）」选择数据文件夹。

仅需已安装的 Python 3（含标准库 tkinter），不需要管理员权限，也不安装任何第三方依赖。完整说明、卸载与排错见 [`PromptSave/native/README.md`](./PromptSave/native/README.md)。

## 快速开始

1. 在任意网页选中一段提示词，右键选择「收藏选中文字」。
2. 在图片上右键选择「收藏图片」；遇到禁用右键的站点，先点工具栏最左侧的监听按钮，再右键「复制图片」。
3. 点击扩展图标打开侧边栏：新建分类、搜索条目、复制提示词，或在设置中导出 ZIP 备份。

## 隐私与安全

- **本地保存**：提示词、参考图和分类保存在本机，不上传至 PromptSave 服务器；扩展不收集遥测，也无需账号。右键收藏网页图片时，扩展会向该图片的源地址请求图片；为支持需登录的站点，请求可能携带该站点的登录凭据。手动导入本地图片和粘贴图片不需要此网络请求。内容安全策略为 `script-src 'self'`，不加载远程脚本。JSZip 在本地打包，仅在使用 ZIP 导入导出时加载（详见 [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md)）。
- **权限用途**：存储、右键菜单、侧边栏、剪贴板、离屏文档与当前标签页权限用于收藏功能；扩展请求所有 `http/https` 站点的主机权限，以便读取用户右键选中的网页图片，安装时统一确认；`file://` 为可选权限，默认不授予。
- **剪贴板监听默认关闭且仅存活于当前会话**，浏览器完全退出后不可能保持监听；后台没有常驻心跳或全站内容脚本，原生桥接连接闲置约 5 秒即断开。
- **本地桥接的安全边界**：宿主程序不联网、不执行任意 shell 命令，只读写授权目录内的 `data.json`、`recovery.json` 与 `images/<id>.jpg`；拒绝路径穿越、符号链接、目录联接与 Windows 设备文件名；所有写入经临时文件原子替换；扩展只保存目录标识，网页无法传入任意绝对路径。
- **脱敏调试日志**：调试页可临时开启日志，事件只包含操作名、错误码与耗时，不包含提示词、图片内容、网址、签名 URL 或目录路径，关闭时即可清除。

## 项目结构

```
.
├── PromptSave/                  # 扩展本体（在浏览器中加载此文件夹）
│   ├── manifest.json            # Manifest V3 清单

│   ├── offscreen/               # 剪贴板图片监听（离屏文档）
│   ├── ui/                      # 界面逻辑、样式、图标与 ZIP 导出
│   ├── shared/                  # 数据模型、图片压缩、校验与原生连接
```

## 测试

项目没有任何 npm 依赖，Node 18+ 自带测试运行器：

```bash
npm test
```

测试覆盖数据模型与合并逻辑、两种存储后端（含写入失败回滚）、图片尺寸校验、剪贴板监听、清单权限与安全检查（动态代码执行、XSS 转义、ZIP 路径穿越等）。浏览器权限、侧边栏、File System Access 与原生桥接的真实行为无法由自动化覆盖，人工验收清单见 [`SMOKE_TEST.md`](./SMOKE_TEST.md)。

## 浏览器兼容性

- 支持 **Chrome 与 Edge** 的桌面版本（Chromium，Manifest V3），依赖侧边栏、离屏文档与 File System Access API。
- 不支持 Firefox 与移动端浏览器；Windows 本地桥接仅支持 Windows。
